PhoneCam - телефон як вебкамера для ПК і OBS (безкоштовно)
==========================================================

Що всередині
  Windows\          - програма для Windows 10/11 (усі 3 файли тримай в одній папці)
  OBS plugin\       - плагін для OBS Studio 28 і новіших
  Застосунок для телефона (PhoneCam.apk) завантажується окремо.


1. ТЕЛЕФОН
  - Встанови PhoneCam.apk на телефон (завантажується окремо). Якщо Android або Play Protect
    попередить - це нормально для застосунку не з магазину:
    «Докладніше» -> «Усе одно встановити».
  - Відкрий застосунок і дозволь доступ до камери.
  - На екрані буде IP-адреса (наприклад 192.168.1.23).
    Телефон і ПК мають бути в одній Wi-Fi мережі.
  - Не згортай застосунок під час трансляції (Android вимкне камеру).
    Екран можна затемнити кнопкою «Затемнити».


2. ПРОГРАМА ДЛЯ ПК
  - Запусти Windows\PhoneCam.exe.
  - Впиши IP з екрана телефона або натисни «Знайти». Коли телефон відповість,
    стануть доступні налаштування камери.
  - Натисни «Підключити».
  - Щоб телефон був вебкою в Discord, Zoom, Telegram, браузері тощо:
    натисни на жовту плашку «Вебку не встановлено» (або шестерню ⚙)
    -> «Встановити вебку» (Windows попросить права адміністратора).
    Потім у потрібній програмі обери камеру «PhoneCam».
  - Шестерня ⚙ - налаштування картинки (експозиція, баланс білого, яскравість,
    контраст, температура тощо). ☀/☾ - світла/темна тема.


3. OBS (можна без програми для ПК)
  - Закрий OBS і запусти «OBS plugin\Install OBS plugin.bat».
    Видалити плагін: «OBS plugin\Uninstall OBS plugin.bat».
  - В OBS: Джерела -> «+» -> «PhoneCam (камера телефона)».
  - Впиши IP або натисни «Знайти телефон у мережі».
  - Програма для ПК і OBS одночасно до телефона не підключаться.


4. КОРИСНЕ
  - 60 FPS через швидкісну зйомку (експериментально): якщо камера телефона
    дає лише 30 кадрів. Краще при доброму світлі.
  - Розумна яскравість PhoneCam: сама витягує картинку, коли мало світла.
  - Фронтальна камера: замість ліхтарика - підсвітка білим екраном.
  - Якщо ліхтарик або зум не відповідають - перепідключись.
  - Заряд телефона видно в програмі для ПК (праворуч від «Підключення»)
    і в меню значка в треї. При 15% і 5% прийде сповіщення.
  - Мова програми: ⚙ -> «Мова» (русский, English, українська).
    Застосунок на телефоні й бот - мовою телефона, плагін OBS - мовою OBS.


5. iPHONE І БУДЬ-ЯКИЙ ТЕЛЕФОН - ЧЕРЕЗ ТЕЛЕГРАМ (без встановлення застосунку)
  - У програмі для ПК обери «Телеграм» і натисни «Підключити» -
    праворуч з'явиться QR-код і код вигляду ABCD-2345.
  - На телефоні наведи звичайну камеру на QR-код - відкриється бот
    @phonecamweb_bot у Телеграмі -> «Запустити» -> «Відкрити камеру».
    Або відкрий бота сам -> «Сканувати QR-код» (або введи код вручну).
  - Дозволь доступ до камери. Далі все як звичайно: вебка, OBS, налаштування.
  - Код запам'ятовується: наступного разу бот підключиться сам.
  - Мінуси порівняно із застосунком: немає 60 FPS через швидкісну зйомку,
    бітрейт підбирається сам, ліхтарик і зум працюють не на всіх телефонах.
    Телеграм не можна згортати й блокувати екран.
  - ПК має бути в інтернеті (для пошуку телефона), відео йде напряму.

6. ПО USB (менша затримка, Wi-Fi не потрібен)
  - На телефоні увімкни «Налагодження по USB» (Налаштування -> Про телефон ->
    7 разів натисни «Номер збірки» -> «Для розробників» -> «Налагодження по USB»).
  - Завантаж Android Platform Tools (безкоштовно, від Google):
    https://developer.android.com/tools/releases/platform-tools
    Поклади adb.exe, AdbWinApi.dll, AdbWinUsbApi.dll поруч із PhoneCam.exe
    (для OBS - розпакуй папку platform-tools у C:\platform-tools).
  - Підключи кабель, дозволь налагодження на телефоні, обери «USB».


Якщо не працює
  - «Телефон не знайдено»: застосунок відкрито? Той самий Wi-Fi? Брандмауер Windows
    може запитати дозвіл - дозволь для приватних мереж. Гостьові мережі та
    деякі роутери не дають пристроям бачити одне одного.
  - «Не знайдено H.264 декодер»: у тебе Windows N - встанови Media Feature Pack.
  - Гальмує по Wi-Fi: зменш якість або підключи по USB.

Якщо Windows сварится при кожному запуску («Не вдалося перевірити видавця»)
  - Розпаковуй архів програмою 7-Zip (https://7-zip.org) - тоді
    попереджень не буде.
  - Або: правою кнопкою по PhoneCam.exe -> Властивості -> галочка
    «Розблокувати» -> ОК (один раз).

Порти: TCP 5757 (відео), UDP 5758 (пошук телефона).

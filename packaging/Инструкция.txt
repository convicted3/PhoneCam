PhoneCam - телефон как вебкамера для ПК и OBS (бесплатно)
=========================================================

Что внутри
  Windows\          - программа для Windows 10/11 (все 3 файла держи в одной папке)
  OBS plugin\       - плагин для OBS Studio 28 и новее
  Приложение для телефона (PhoneCam.apk) скачивается отдельно.


1. ТЕЛЕФОН
  - Установи PhoneCam.apk на телефон (он скачивается отдельно). Если Android или Play Protect
    предупредит - это нормально для приложения не из магазина:
    «Подробнее» -> «Всё равно установить».
  - Открой приложение и разреши доступ к камере.
  - На экране будет IP-адрес (например 192.168.1.23).
    Телефон и ПК должны быть в одной Wi-Fi сети.
  - Не сворачивай приложение во время трансляции (Android выключит камеру).
    Экран можно затемнить кнопкой «Затемнить».


2. ПРОГРАММА ДЛЯ ПК
  - Запусти Windows\PhoneCam.exe.
  - Впиши IP с экрана телефона или нажми «Найти». Когда телефон ответит,
    станут доступны настройки камеры.
  - Нажми «Подключить».
  - Чтобы телефон был вебкой в Discord, Zoom, Telegram, браузере и т.д.:
    нажми на жёлтую плашку «Вебка не установлена» (или шестерёнку ⚙)
    -> «Установить вебку» (Windows попросит права администратора).
    Потом в нужной программе выбери камеру «PhoneCam».
  - Шестерёнка ⚙ - настройки картинки (экспозиция, баланс белого, яркость,
    контраст, температура и т.д.). ☀/☾ - светлая/тёмная тема.


3. OBS (можно без программы для ПК)
  - Закрой OBS и запусти «OBS plugin\Install OBS plugin.bat».
    Удалить плагин: «OBS plugin\Uninstall OBS plugin.bat».
  - В OBS: Источники -> «+» -> «PhoneCam (камера телефона)».
  - Впиши IP или нажми «Найти телефон в сети».
  - Программа для ПК и OBS одновременно к телефону не подключатся.


4. ПОЛЕЗНОЕ
  - 60 FPS через скоростную съёмку (экспериментально): если камера телефона
    даёт только 30 кадров. Лучше при хорошем свете.
  - Умная яркость PhoneCam: сама вытягивает картинку, когда мало света.
  - Фронтальная камера: вместо фонарика - подсветка белым экраном.
  - Если фонарик или зум не отвечают - переподключись.
  - Заряд телефона виден в программе для ПК (справа от «Подключение»)
    и в меню значка в трее. При 15% и 5% придёт уведомление.
  - Язык программы: ⚙ -> «Язык» (русский, English, українська).
    Приложение на телефоне и бот - на языке телефона, плагин OBS - на языке OBS.


5. iPHONE И ЛЮБОЙ ТЕЛЕФОН - ЧЕРЕЗ ТЕЛЕГРАМ (без установки приложения)
  - В программе для ПК выбери «Телеграм» и нажми «Подключить» -
    справа появится QR-код и код вида ABCD-2345.
  - На телефоне наведи обычную камеру на QR-код - откроется бот
    @phonecamweb_bot в Телеграме -> «Запустить» -> «Открыть камеру».
    Или открой бота сам -> «Сканировать QR-код» (или введи код руками).
  - Разреши доступ к камере. Дальше всё как обычно: вебка, OBS, настройки.
  - Код запоминается: в следующий раз бот подключится сам.
  - Минусы по сравнению с приложением: нет 60 FPS через скоростную съёмку,
    битрейт подбирается сам, фонарик и зум работают не на всех телефонах.
    Телеграм нельзя сворачивать и блокировать экран.
  - ПК должен быть в интернете (для поиска телефона), видео идёт напрямую.

6. ПО USB (меньше задержка, Wi-Fi не нужен)
  - На телефоне включи «Отладку по USB» (Настройки -> О телефоне ->
    7 раз нажми «Номер сборки» -> «Для разработчиков» -> «Отладка по USB»).
  - Скачай Android Platform Tools (бесплатно, от Google):
    https://developer.android.com/tools/releases/platform-tools
    Положи adb.exe, AdbWinApi.dll, AdbWinUsbApi.dll рядом с PhoneCam.exe
    (для OBS - распакуй папку platform-tools в C:\platform-tools).
  - Подключи кабель, разреши отладку на телефоне, выбери «USB».


Если не работает
  - «Телефон не найден»: приложение открыто? Тот же Wi-Fi? Брандмауэр Windows
    может спросить разрешение - разреши для частных сетей. Гостевые сети и
    некоторые роутеры не дают устройствам видеть друг друга.
  - «Не найден H.264 декодер»: у тебя Windows N - установи Media Feature Pack.
  - Тормозит по Wi-Fi: уменьши качество или подключи по USB.

Если Windows ругается при каждом запуске («Не удаётся проверить издателя»)
  - Распаковывай архив программой 7-Zip (https://7-zip.org) - тогда
    предупреждений не будет.
  - Или: правой кнопкой по PhoneCam.exe -> Свойства -> галочка
    «Разблокировать» -> ОК (один раз).

Порты: TCP 5757 (видео), UDP 5758 (поиск телефона).
